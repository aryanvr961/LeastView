# Changelog

## 0.1.0

First public release.

### Viewing
- PDF viewer with stacked pages, zoom around the fingers, double-tap zoom and a page scroller.
- DOCX, XLSX and PPTX viewers built on their own parsers (styles, lists, tables, images, number formats, merged cells, slide layouts and masters).
- TXT and image viewers. "Open with LeastView" for PDF, DOCX, XLSX, PPTX and TXT.

### Editing
- DOCX rich-text editing with undo / redo, XLSX cell editing, PPTX text editing, and text-only editing of PDF lines.
- Saves back to the original file after verifying the written file, with "Save a copy" as a fallback.

### Search
- Home search by file name with type filters.
- In-document search with highlights, result counter and previous / next for PDF, DOCX, XLSX and PPTX.

### Tools
- **Resizer** for images, PDF, DOCX, PPTX and XLSX.
- **Mergers** for PDF, TXT, images and Office files (as PDF).
- **Splitter** for PDFs by ranges, single pages or every N pages.
- Recent-files picker with previews, and one-tap "Save to Documents".

### Known gaps
See the README's *Known limitations*.
